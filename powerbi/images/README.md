## Cómo exportar una imagen desde Power BI Desktop

- **Captura rápida:** abre la página en Power BI Desktop y usa la herramienta
  *Recorte* de Windows (`Win` + `Shift` + `S`) para capturar el lienzo. Pega y
  guarda como `.png` con el nombre correspondiente.
- **Exportación limpia:** *Archivo → Exportar → PDF* y luego recorta cada página,
  o exporta cada visual con los tres puntos → *Exportar datos/imagen*.

## Notas

- Usa formato **PNG** (mejor nitidez para capturas de UI).
- Recomendado: resolución de al menos 1600 px de ancho.
- Recuerda que los datos son **simulados**; no hace falta ocultar información.
